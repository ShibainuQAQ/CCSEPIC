# 开源夹爪打印包（2026-09-17）

> **队内参考资料，不进比赛提交件。** 许可与来源见 `06_来源与许可.md`。
> 目的：给"龙门 XYZ + 托盘"的分拣机准备一套**能直接打印、抓得稳**的开源夹爪（验证件/对手件）。

## 3 分钟上手

| 步骤 | 做什么 | 去哪 |
|---|---|---|
| 1 | 切片 `01_打印文件\整版_SO-ARM夹爪_154x154_全部件.stl` → PLA+ / 0.2mm / 4 墙 / 25% 填充 / **不开支撑** | 9 个结构件一盘出（154×154×52） |
| 2 | 再打 `补打_固定销x2.stl`（**整版里缺这 2 个小销**）+ `爪垫_锯齿_70x14x2.stl` ×2（TPU 95A） | 齿条/齿轮想更顺可改 0.12mm / 100% 填充单打 |
| 3 | 按 `03_硬件清单与采购.md` 买舵机 / 轴承 / 导杆 / 螺钉 | 原样复刻 ≈ ¥300~420 |
| 4 | 按 `04_装配与调试.md` 装（9 步，含舵机限矩设置） | 关键：**Max Torque Limit = 500** |
| 5 | 抓不牢 / 抓不稳 → 看 `05_抓取稳定性.md` | 结论：瓶颈是**爪面摩擦**，不是夹持力 |

## 三条先知道

| # | 事项 | 说明 |
|---|---|---|
| ① | **它进不了我们的储物盒** | 夹爪外廓 **128（宽）× 109（深）× 130.5（高）mm**，我们盒内只有 **82×82**、盒口距台面 48 —— 塞不进去。用它只能**在盒口上方 20~30mm 投放**（详见 `00_索引与选型.md` §3） |
| ② | **合规** | 工创赛禁"成品套件拼装"、非标件须自主设计制造；A2 创意由专家打分、**同校外形雷同全 0**。这份包**只在队内用**：当验证件、当对手件、当构型参考；正式提交件仍用我方自研夹爪（76mm 宽、能进盒） |
| ③ | **舵机不通用** | 原设计用 **Feetech STS3215（12V 串行总线舵机，RS485/TTL）+ Waveshare 总线转接板**；我们已买的是 **DS3225（PWM，25kg，270°）**。两条路见 `03_硬件清单与采购.md` §2 |
