# 装配与调试（9 步 + 我们自己的接口）

> 队内资料。原文：`参考\SO-ARM夹爪\docs\assembly-guide.md` + `Assembly Guide Follower Gripper.pdf`（含图）。
> 下面按我们的场景重写：**省掉 SO-ARM 机械臂那一步，换成"接到龙门 Z 轴"**。

---

## 1 需要的工具

| 工具 | 规格 | 用途 |
|---|---|---|
| 十字螺丝刀 | PH1 | 舵机自攻螺钉 |
| 内六角 | H1.5（M2）、H2.0（M3）、H2.5（M4） | 全部内六角螺钉 |
| 尖嘴钳 / 小台钳 | — | 压 Ø6 杆、压轴承 |
| 上位机 | Windows + 总线舵机调试工具 | 设 `Max Torque Limit`（路线 A 必做） |

## 2 装配 9 步

| 步 | 做什么 | 用的件 | 关键点 |
|:--:|---|---|---|
| 1 | **齿轮装舵盘** | 齿轮 + 舵机自带圆盘 + 4×M3×4 紧定 + 1×M3×6 | 从舵盘一侧往齿轮拧，**拧紧后盘与齿轮之间不能有缝**；再整体压到舵机输出轴上，用 M3×6 锁住 |
| 2 | **舵机限矩（别跳）** | 总线转接板 + 上位机 | 1 Mbps 连上 → 勾选使能扭矩 → **`Max Torque Limit` 设 500** → Save。**不设的话第一次夹到硬物会把机构顶坏** |
| 3 | **夹爪 + 齿条 + 销** | 2×夹爪 + 2×齿条 + **2×销（补打件）** | 齿条从**侧面**插进夹爪；销从**背面**插到底，卡住齿条（不装销，齿条会窜） |
| 4 | **穿导杆** | 2×Ø6×125 杆 | 两根杆同时穿过两片夹爪的星形孔；杆长了锯到 125 |
| 5 | **主框装轴承** | 2×MF106ZZ + 2×M4×8 | 轴承**法兰面朝上**压入，各用 1 颗 M4×8 压住 |
| 6 | **合装** | 步 4 的组件 + 主框 | 把两根杆"咔"进主框；把两爪推到左右极限 |
| 7 | **舵机装主框** | 3×自攻（舵机自带） | 先对中位再上螺钉，避免装上后爪不对中 |
| 8 | **装连接耳 → 换我们的 Z 轴转接板** | `060.080 安装支架`（或 `060.074 相机支架`） | 原设计是拧到机械臂腕部舵盘上；**我们改成：把 060.080 当连接耳，自画一块转接板接到 Z 轴滑块**（见 §3） |
| 9 | **（可选）装相机** | 相机 + `060.090 垫片` + 4×M2×8 + 4×M2 螺母 | 我们是"相机在上方看料盘"，**夹爪上不需要装相机**，这步可以跳过 |

---

## 3 我们额外要做的：Z 轴转接板

| 项 | 内容 |
|---|---|
| 现有接口 | 夹爪侧的连接耳 `RB9.01.060.080 安装支架`（17×48×37），用 4×M3×6 与主体相连；它的另一面是给 SO-ARM 腕部的 |
| 我们要的 | Z 轴滑块（我方 4040/MGN12 滑块）→ 该连接耳 |
| 怎么做 | 在 Fusion 打开 `参考\SO-ARM夹爪\models\RB9.01.062.000 Gripper.STEP`，量出连接耳那 4 个 M3 孔的位置与间距，画一块 3~4mm 铝板/PLA 板（两边孔位各一组），M3 螺钉对锁；**铝板优于打印件**（Z 轴是悬臂，抗弯） |
| 校核 | 装上后手压夹爪尖端 5N，测变形 <1mm；不行就加厚到 5mm |

## 4 通电自检（5 分钟）

| 检查 | 方法 | 合格判据 |
|---|---|---|
| 中位 | 给中位指令 | 两爪对称、开口约 42mm（行程一半） |
| 同步 | 慢速全开→全闭 3 次 | 两爪**同步**、无异响、无卡顿 |
| 回差 | 夹住 20mm 方块，手左右轻推 | 位移 ≤ 0.3mm |
| 行程 | 全开 → 量开口 | ≈ 84mm |
| 限矩 | 空夹到极限并保持 2s | 舵机不尖叫、机构不响 |
| 温升 | 连续动作 20 次 | 舵机外壳温热不烫手 |

## 5 常见故障 → 处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 开合卡滞、一顿一顿 | 齿条/齿轮层高太粗、有毛刺；轴承螺钉压太紧 | 齿条齿轮重打 `0.12mm / 100%`（关熨烫）；M4 轴承螺钉松 1/4 圈 |
| 两爪不同步、歪 | 齿轮与舵盘没贴合；齿条某一侧销没插到底 | 拆开重装步 1、步 3 |
| Ø6 杆装不进 / 太晃 | 夹爪星形孔档位不对 | 打 `Gripper test plate star holes 6.0-6.3.STL` 挑档，再打对应 `D6.x` 夹爪 |
| 夹住后货物打滑 | 爪面光滑（PLA μ≈0.3） | **贴爪垫**（`爪垫_锯齿_70x14x2.stl`，TPU）或 1.5mm 3M 背胶硅胶垫 |
| 舵机发热/异味 | 限矩没设或设太大；堵转 | 确认 `Max Torque Limit=500`；检查机构是否卡死 |
| 齿轮打齿 | 打印填充不足 / 撞击 | 齿轮齿条改 100% 填充重打；加软启动（闭合前 200ms 降速） |
| 投放时货物弹跳出台 | 落料高度太高 | 盒口上方 20~30mm 松开；盒底垫 2mm 硅胶/泡棉 |

## 6 装到整机上以后（与运动程序的约定）

| 约定 | 值 | 原因 |
|---|---|---|
| 取料高度 | 爪垫中心对货物**中上部** | 重心之上，抗摆动 |
| 闭合后保持 | 80~120 ms 再抬升 | 消除齿条空程、让爪垫完全贴合 |
| 抬升速度 | ≤ 150 mm/s | 抑制货物摆动 |
| 横移速度 | ≤ 300 mm/s，加减速 ≤ 1000 mm/s² | 惯性力 ≈ 0.1N，远小于摩擦力（见 `05_抓取稳定性.md`） |
| 投放方式 | **盒口上方 20~30mm 松开** | 这套夹爪 128×109 进不了 82mm 盒口 |
| 落料确认 | 入盒对射传感器 + 松开后停 100ms | 本次件无夹持反馈；总线舵机可读负载做辅助判据 |
