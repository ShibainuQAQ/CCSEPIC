## 4 使用红线（三条，联赛规则）

1. **不要把它的 STL 直接打印出来当我们的比赛件。** 工创赛规则：禁成品套件拼装、非标件须自主设计制造；
   A2 创意由专家打分、**同校外形雷同全 0**。→ 正确姿势：**只借构型**（齿条同步 + 平行自定心 + T 槽/导杆导向），
   按我们自己的货物与盒子重新建模（我方版本见 `03_设计与尺寸\夹爪设计参数表.md`）。
2. **它的文档与图片是 CC BY 4.0，用了就得署名** —— 与"提交件匿名"直接冲突。→ 说明书里的夹爪机构图**自己画**；
   它的装配图/规格图只在队内看。
3. **署名只留在队内**（本文件夹 + `参考\SO-ARM夹爪\来源与许可.md`），与 `开源\` 四篇（西安理工，CC BY-NC-SA）同一做法。

> 若将来确实要复用它的某个零件几何（目前没必要），必须随件附 `HARDWARE-LICENSE.txt` 并在队内记明来源 ——
> **不要让它出现在匿名提交件里**。

## 5 复现

```powershell
# 1) 重新拉上游文件（走镜像，Python）
python "05_工具与校核\gh_mirror.py" get roboninecom/SO-ARM100-101-Parallel-Gripper `
    "models/Follower gripper (165x165 bed size).STL" "models/parts/RB9.01.062.100 Nail.STL" `
    --out "_download/SO-ARM"

# 2) 重新生成整个打印包（拆件 / 补打盘 / 爪垫 / 渲染 / 校验）
python "_work\build_package.py"

# 3) 只想量个 STL / 拆件 / 摆盘 / 渲染
python "05_工具与校核\stl_tool.py" info   <文件.STL>
python "05_工具与校核\stl_tool.py" split  <文件.STL> <输出目录>
python "05_工具与校核\stl_tool.py" plate  <输出.STL> <件.STL>:<份数> ...
python "05_工具与校核\stl_tool.py" render <文件.STL> <输出.png> --view top|front|side

# 4) 重新生成爪垫（换尺寸/齿数）
python "05_工具与校核\grip_pad_gen.py" <输出目录> --len 70 --wid 14 --thk 2 --teeth 5 --tooth 0.8
```
