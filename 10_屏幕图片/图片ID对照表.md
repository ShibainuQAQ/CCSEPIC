## 图片尺寸（重要）

| 项 | 值 |
|---|---|
| 屏分辨率 | **800 × 480**（工程里 `page0` 的 w/h = 800/480，**不是** 3.5″ 480×320） |
| 图片控件尺寸 | **112 × 112**（`p0`~`p5` 的 w/h 都是 112） |
| 屏内图片尺寸 | **112 × 112**（工程里资源图实测就是 112×112，与控件一致 ✅） |
| ⚠️ 我方旧的 `发布\00.jpg…19.jpg` | **160×160，尺寸不对，从未被导入屏里** → 作废（可留档，别再用） |
| 要重新导图时 | 必须 **112×112**，并**按 ID 顺序**「添加图片」，否则 ID 会变 |
