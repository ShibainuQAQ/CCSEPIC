# 接线总表 · **STM32F103C8T6** 版（2026-10-04 修订）

> 背景：原 **RCT6** 板因接线短路"很烫"报废 ✗ → 改用 **C8T6**（48 脚·中容量）。
> 固件已移植并**编译通过**：`-DSTM32F10X_MD`、64K flash / 20K RAM、栈顶 `0x20005000`
> ⇒ **ROM 22.5KB / 64KB，RAM 1.9KB / 20KB** ✓
>
> ⚠️⚠️ **上电前先做第 5 节的防短路检查** —— 上一块板就是这么烧的 ✗
> ⭐ 本版**不使用无线桥 ESP32-C6** ✗（用户 2026-10-04 决定）⇒ **USART2 给了串口屏** ✓

---

## 1. 一根线一张表（照这个接，按"从 → 到"读）

### ① 调试口（PC 看日志 / 发命令）

| 从 | 到 | 说明 |
|---|---|---|
| USB-TTL 的 **TXD** | C8T6 **PA10** | STM32 的 RX |
| USB-TTL 的 **RXD** | C8T6 **PA9** | STM32 的 TX |
| USB-TTL 的 **GND** | C8T6 **GND** | ⭐ 必须 |

**参数：115200 8E1** ⚠️（8N1 会是乱码）
⚠️ 经典蓝板**没有板载 USB 转串口** ✗ → 必须用 USB-TTL 转接板；若是"带 CH340 的 C8T6 板"则直接插 USB ✓

### ② 串口屏（淘晶驰）—— ⭐ 从 PB8 改到 PA2/PA3

| 从 | 到 | 说明 |
|---|---|---|
| C8T6 **PA2**（USART2_TX） | 屏的 **RX** | 固件→屏 |
| 屏的 **TX** | C8T6 **PA3**（USART2_RX） | 屏→固件（触摸事件，可不接） |
| 屏的 **GND** | C8T6 **GND** | ⭐ 必须 |
| 屏的 **5V** | 5V 逻辑电源 | 别从板子 5V 脚取大电流 ✓ |

**参数：8N1，出厂 9600** ⚠️ 屏侧波特率必须与固件一致（`LCDBAUD <n>` 可改固件侧 ✓）

### ③ 视觉板 CanMV/K210 —— ⭐ 从 PC10/PC11 改到 PB10/PB11

| 从 | 到 | 说明 |
|---|---|---|
| K210 的 **TXD** | C8T6 **PB11**（USART3_RX） | 计划/识别结果进来 |
| C8T6 **PB10**（USART3_TX） | K210 的 **RXD** | 回执出去 |
| K210 的 **GND** | C8T6 **GND** | ⭐ 必须 |

**参数：115200 8N1** ✓
⚠️ 这块 K210 板上标的 `TXD/RXD` **就是它的 UART2（控制台，与 USB 同一路）** ✓ 已实测
⚠️ 所以固件对这个口**只认 `@` 开头的行**、其余静默忽略 ✓（REPL 的输出不会误触发机构 ✓）

### ④ X 步进（X42 驱动器）

## 3. 电源与共地（星形）

```
6S 电池 25.2V → 总开关 → 保险丝 →【急停（常闭，串在动力回路里）】
   ├──────────────────────> X42 / Y42 的 V+           ← 25.2V 直连 ✓
   ├─ 降压 5.5~6.0V / ≥3A ─> 两个舵机 V+（并 470~1000µF）
   └─ 降压 5V ────────────> 蓝板 5V 脚 ／ 串口屏 ／ K210
                              └─ 板载 3.3V ─> 6 路红外接收端
```

⭐ **所有"−"必须汇到同一个点**：电池 −（含两个驱动器的 G）＋ 舵机电源 − ＋ 蓝板 GND ＋ 屏 GND ＋ K210 GND ＋ USB-TTL GND

⚠️ **舵机/步进的电流绝不许走蓝板的地线或 5V 脚** ✗ —— 这是烧板第一原因

## 4. 上电顺序（严守）

| 步 | 上什么 | 检查什么 |
|---|---|---|
| 1 | **只插 USB-TTL**（不接动力 ✓） | 能看到 `LOG boot …`；发 `PING` → `OK pong` ✓ |
| 2 | **5V 逻辑**（屏 / K210） | 各板电源灯亮 ✓ |
| 3 | **舵机 6V** | `ZSET 1500`、`GSET 1450` 能动 ✓ |
| 4 | **最后上 25.2V** | 电机自锁（手拧不动）✓ |
| 5 | 全程 | ⚠️ 任何一块**发烫立刻断电** ✗ |

| 入盒红外 1~6 | PC0 ~ PC5 | ⭐ **PB12 / PB13 / PB14 / PB15 / PA8 / PA11** |
| 无线桥 ESP32-C6 | PA2 / PA3 | ❌ **不接了**（用户决定） |
| 调试口 / 步进 / 舵机 / SWD | — | **完全不变** ✓ |
