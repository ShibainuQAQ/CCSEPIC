# 智能分拣装置 · 校选方案说明书

> 版本：2026-09-15（按本赛项 II-2 官方命题要求与评分细则编写）
> 说明：本说明书为匿名评审件，全文不出现校名、姓名、地名与赛项全称。

## 1 引言与赛项理解

### 1.1 赛项任务

本赛项要求自主设计并制作一台**静态智能分拣装置**：比赛时裁判将若干货物随机倒入托盘，装置在无任何人工干预的情况下，自动完成货物的**识别、分类与储存**——把形状相同且颜色相同的货物放入同一个储物盒，并在显示屏上逐件显示分拣信息。

### 1.2 规则要点摘要

表 1 规则硬性要求摘要

| 项目 | 要求 |
|---|---|
| 作品组成 | 储物盒 ×6 + 分拣机构 + 托盘（可组合式或整体式） |
| 外形尺寸 | 整体不超过 350×350×450mm（长×宽×高） |
| 托盘 | 不小于 160×160mm，边缘高度不小于 10mm |
| 储物盒 | 6 个独立储物盒；每盒须能完全容纳分拣入盒的货物（不超过 4 个） |
| 货物 | 尺寸在 40mm 正方形范围内（含薄壁件）；附有模拟污渍、缺陷的图形、文字、二维码等信息；初赛货物不少于 12 件、种类不少于 6 种 |
| 归类规则 | 形状相同且颜色相同的货物放入同一个储物盒 |
| 供电 | 仅允许 1 个装在装置内部的电源，种类不限，比赛（含调试）过程中不得更换 |
| 通讯 | 允许与笔记本电脑通讯；运行过程中不得触碰笔记本；禁止任何形式的遥控 |
| 启动 | 裁判指令后一键启动；启动后再次接触装置（含笔记本）本轮结束 |
| 显示 | 高亮显示屏（仅显示功能），支持各种格式图片播放；逐件显示序号、货物名称、货物图片、分拣成功总数量 |
| 时间与轮次 | 每轮调试 3 分钟 + 运行 3 分钟，两次运行机会取最好成绩 |
| 结束条件 | 15 秒无动作或无显示本次分拣信息，本轮结束；货物掉落（装置内或装置外），本轮结束 |

表 2 现场初赛计分规则摘要

| 情况 | 得分 |
|---|---|
| 储物盒中仅有 1 个货物 | 2 分 |
| 多个同色同形货物放入同一储物盒 | 每个 5 分（货物须全部入盒） |
| 不同颜色或不同形状货物混入同盒（含部分进入） | 不得分 |
| 正确显示分类信息（序号/名称/图片/总数） | 每条 2 分，有错不得分 |
| 信息未显示即分拣下一件 | 不得分 |
| 货物掉落（装置范围内或装置外） | 本轮结束 |

### 1.3 设计约束分析

由规则可提炼出四个对设计起决定作用的约束：

表 3 规则约束与设计对策

| # | 规则约束 | 对设计的要求 |
|---|---|---|
| 1 | 掉落即本轮结束，且货物仅 40mm 级 | 抓取与搬运环节的**可靠性与定位精度**是第一指标，机构选型向精度倾斜 |
| 2 | 同形同色归一盒计 5 分/件，混盒不得分 | 识别必须**形状+颜色双判据**，且要有入盒结果的硬件确认 |
| 3 | 逐件分拣，显示完成才能分下一件 | 软件状态机须把"显示完成"作为**硬门禁**，并配合超时机制规避 15 秒判负 |
| 4 | 货物随机倒入托盘，位置方向随机 | 必须**俯视成像 + 坐标标定**，先定位后抓取，不能用固定动作盲抓 |

## 2 机械结构设计

### 2.1 总体布局

装置采用**整体式**布局：底板（350×350mm 级）上，托盘位于前方正中，6 个储物盒分两列布置于后方两侧，龙门架横跨托盘与储物盒上方，俯视相机固定于托盘正上方。整机外形控制在 350×350×450mm 以内。

表 4 整机布局规划

| 区域 | 内容 | 备注 |
|---|---|---|
| 前方中部 | 托盘（160×160mm，边缘高 10mm） | 倒货区，货物随机落入 |
| 托盘正上方 | 俯视相机 + 环形补光 | 固定安装，视野覆盖整个托盘 |
| 后方两侧 | 储物盒 2 列 × 3 个 | 每盒配 1 路入盒检测 |
| 横跨上部 | 龙门架（X/Y 轴）+ Z 升降 + 夹爪 | 工作空间覆盖托盘与全部储物盒 |
| 底板下部/背部 | 主控、电源、驱动器、走线 | 模块化固定，便于拆装检修 |
| 醒目位置 | 彩色显示屏、一键启动按钮、急停开关 | 显示屏不被遮挡 |

### 2.2 分拣机构：龙门 XYZ + 电动夹爪

表 5 机构方案对比与选型（已定论）

| 候选方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 多自由度舵机关节臂 | 结构紧凑、外观科技感强 | 多舵机串联末端重复定位精度差，存在同赛事强队翻车先例；40mm 小货物+掉落判负规则下风险不可接受 | 放弃 |
| SCARA 旋转臂 | 结构较简单 | 需运动学解算，关节间隙影响精度，调试链路长 | 放弃 |
| 吹气/拨杆分度 | 机构最简单 | 货物随机姿态不可控，掉落风险高（掉落即本轮结束） | 放弃 |
| **龙门 XYZ + 电动夹爪** | 直角坐标系精度高、无运动学解算；相机俯视坐标与机构坐标一一对应，标定简单；结构成熟 | 结构件较多、外观偏"工业" | **选用** |

表 6 分拣机构各轴设计

| 轴 | 驱动 | 传动 | 定位方式 |
|---|---|---|---|
| X 轴（横移） | 闭环步进电机（脉冲版） | 同步带 + 光轴直线导轨 | 微动开关回原点 + 闭环步进位置控制 |
| Y 轴（纵移） | 闭环步进电机（脉冲版） | 同步带 + 光轴直线导轨 | 微动开关回原点 + 闭环步进位置控制 |
| Z 轴（升降） | PWM 舵机 | 平行四边形连杆（保持夹爪姿态） | 高位/低位两端点，微动开关低位确认 |
| 夹爪 | PWM 舵机 | 3D 打印夹爪（快拆模块） | 微动开关夹合到位检测 |

选型理由：闭环步进不丢步、位置可控；同步带传动精度高于齿轮齿条（同赛事强队曾因齿轮齿条精度损失分数的公开教训）；Z 轴仅需高位/低位两个端点，舵机加连杆即可满足，无需丝杆，简化结构。

### 2.3 托盘与储物盒

- **托盘**：3D 打印/板材制作，内空 ≥160×160mm，边缘高 10mm；底部平整、浅色哑光，兼顾货物防滑与视觉识别对比度。
- **储物盒 ×6**：3D 打印，独立可拆；盒口做导向斜面便于货物滑入；每盒侧壁开孔安装反射式光电开关，确认货物**完全入盒**（规则：未全部进入不计数）。内腔尺寸按**完全容纳 4 件 ≤40mm 货物**校核（规则要求每盒须能储存不超过 4 个货物），避免因容量不足被判不合格。

### 2.4 模块化与可维护性

- 各功能模块（龙门组件、夹爪组件、储物盒、电控仓）之间采用螺栓连接，**任一模块拆卸不超过 5 颗螺丝**；
- 夹爪为**快拆模块**：决赛创新实践环节需按现场命题改制执行件，快拆结构可最大限度压缩现场改制时间；
- 正式结构件加工前，先用木板/KT 板切样验证装配关系。

## 3 电控系统设计

### 3.1 总体架构

表 7 电控系统组成

| 模块 | 选型 | 职责 |
|---|---|---|
| 主控 | STM32F103RCT6 | 步进脉冲控制、舵机 PWM、状态机、串口通信、入盒检测 |
| X/Y 驱动 | 闭环步进电机驱动器（脉冲版）×2 | 接收脉冲/方向信号，闭环防丢步 |
| Z/夹爪 | 25kg 级 PWM 舵机 ×2 | 升降与开合 |
| 入盒检测 | 反射式光电开关 ×6 | 每盒货物落入确认 |
| 到位检测 | 微动开关 ×5 | X/Y 原点、Z 低位、夹爪到位 |
| 显示 | 3.5 寸串口彩屏（480×320） | 逐件显示序号/名称/图片/总数 |
| 通讯 | USB 转 TTL（CH340） | 笔记本识别结果下发 |

### 3.2 电源系统

表 8 电源分配方案

| 支路 | 电压 | 供电对象 | 实现方式 |
|---|---|---|---|
| 动力支路 | 24V 直通 | 步进驱动器 ×2 | 电池经总开关、保险丝直供 |
| 舵机支路 | 7.4V / 5A | 舵机 ×2 | 独立 DC-DC（XL4015） |
| 逻辑支路 | 5V / 3A | 主控、传感器、显示屏 | 独立 DC-DC（LM2596/Mini360） |

- 电源为**单包 6S（24V）锂聚合物电池**，装于装置内部，符合"单一内置电源、赛中不更换"的要求；
- **舵机与主控分开供电**并在舵机支路就近加储能电容，避免舵机大电流冲击导致主控复位；
- 配备电源总开关、保险丝、低压报警蜂鸣器、急停开关与带标识的一键启动按钮。

### 3.3 可靠性与安全

- 运动机构走线采用柔性拖链电缆，随龙门运动往复弯折不破皮（有赛事中排线磨破导致短路烧毁主控的公开教训）；
- 主回路串联保险丝；急停开关切断动力支路；
- 所有接插件焊接加固，线束整理固定，防止运行振动松脱。

## 4 视觉与识别系统设计

### 4.1 识别任务分析

规则要求识别货物的**颜色、形状、文字、图像、二维码**等信息，且货物带有模拟污渍与缺陷干扰。采用"**笔记本 + 俯视 USB 摄像头**"方案：规则明确允许与笔记本电脑通讯，识别结果经串口下发主控。笔记本算力充足，可运行 OpenCV 完成多特征识别，开发调试效率远高于嵌入式视觉模块。

### 4.2 识别流程

表 9 视觉识别流程

| 步骤 | 内容 |
|---|---|
| 1 取图 | 俯视摄像头固定拍摄托盘；锁定手动曝光 + 环形补光，压制环境光与频闪干扰 |
| 2 分割 | HSV 颜色空间阈值分割得到候选货物区域，形态学去噪、面积限幅（抗污渍干扰） |
| 3 分类 | 颜色直方图判色；轮廓特征（顶点数、圆度、长宽比、Hu 矩）判形状；`QRCodeDetector` 读二维码 |
| 4 定位 | 轮廓质心 + 最小外接矩形给中心坐标与姿态角 |
| 5 标定 | 九点标定建立像素坐标到托盘平面坐标的映射；托盘坐标系与龙门 X/Y 坐标系重合，直接换算目标点 |
| 6 下发 | 识别结果（种类、坐标、角度）经串口定长协议发 STM32 |

### 4.3 抗干扰与确认机制

- 连续多帧识别一致才采信，单帧异常直接重拍；
- 污渍/文字造成的伪轮廓用面积与形状特征双重过滤；
- 调试阶段预留串口在线调阈值接口，适配赛场光线差异。

## 5 软件流程设计

### 5.1 主状态机

表 10 主状态机状态表

| 状态 | 动作 | 转移条件 |
|---|---|---|
| 待机 | 上电自检、各轴回原点、屏显就绪画面 | 一键启动按下 |
| 识别 | 通知笔记本拍摄识别，接收货物清单 | 收到完整清单/超时重拍 |
| 规划 | 按"同形同色归一盒"生成分拣序列与目标盒号 | 序列生成完毕 |
| 取货 | X/Y 移至目标上方 → Z 降 → 夹合（到位确认）→ Z 升 | 夹爪到位开关闭合 |
| 放货 | X/Y 移至目标盒上方 → Z 降 → 松开 → Z 升 | 入盒光电触发确认 |
| 显示 | 串口屏刷新：序号/名称/图片/成功总数 | **显示完成后才允许进入下一件（硬门禁）** |
| 完成/异常 | 全部分完停机；任一动作超时进入重试或放弃该件 | 15 秒判据兜底 |

### 5.2 关键时序与异常处理

- **显示门禁**：状态机中"显示完成"是进入下一次抓取的强制前置条件，对应规则"信息未显示即分拣下一件不得分"；
- **超时与重试**：每个动作设超时；识别存疑重拍、抓空重抓（限次数），宁可放弃一件也不卡死整轮（15 秒无动作本轮结束）；
- **入盒确认**：光电开关未触发则视为未入盒，不计入成功数量，屏显不出现虚假计数。

### 5.3 通讯协议

笔记本 → STM32 单向串口下发，定长帧含帧头校验：货物种类编号、中心坐标、姿态角；STM32 → 串口屏为串口指令（图片与界面元素预存屏内，仅发切换指令，响应快、不占用主控资源）。

## 6 风险分析与对策

表 11 主要风险与对策

| # | 风险 | 后果 | 对策 |
|---|---|---|---|
| 1 | 抓取/搬运中货物掉落 | **本轮直接结束** | 夹爪做仿形内衬+包络式夹持；Z 升降降速；路径避开其它货物；抓取前视觉复核目标位姿 |
| 2 | 污渍/文字干扰导致误分类 | 混盒不得分 | 多帧确认、面积限幅、形状多特征联合判决；存疑重拍 |
| 3 | 赛场光线变化 | 识别率下降 | 锁手动曝光+自带补光；调试 3 分钟内在线调阈值 |
| 4 | 舵机无反馈导致动作不到位 | 抓空/碰货 | 全部动作配微动开关到位检测，禁止纯延时 |
| 5 | 步进低速振动、丢步 | 定位漂移 | 闭环步进防丢步；驱动器细分+加减速曲线抑制振动 |
| 6 | 线束磨破短路 | 设备损坏 | 拖链电缆+缠绕管理线，焊点热缩管绝缘 |
| 7 | 程序卡死 | 15 秒判负 | 全链路超时看门狗，任何环节可放弃当前件保底 |
