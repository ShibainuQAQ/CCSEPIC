本目录存放装置的机械模型，**分「我方自研」和「第三方开源参考件」两部分**，许可不同，请留意。

| 目录 / 文件 | 内容 | 格式 |
|---|---|---|
| `夹爪/方案1/` | 早期夹爪方案：主框架 + 铲子主动轮 / 从动轮 | `.SLDPRT` `.STEP` `.3mf` `.stl` |
| `夹爪/方案2/` | **平行两指 + 双齿条自定心夹爪**（最终采用）：`out/parts/` 下按零件分目录，每个零件含 `stl/` 打印网格 + `.step` 通用格式 + 部分 `.SLDPRT` 源文件；`out/夹爪总成_ASM.step` 为整机装配 | `.SLDPRT` `.STEP` `.STL` |
| `龙门架/` | X/Y 龙门结构件：钢轨固定座、钢管固定座、皮带卡槽、舵机固定件等 | `.SLDPRT` |
| `置物架/` | 储物盒支撑架、物料桶、亚克力板支撑 | `.SLDPRT` |
| `滑梯/` | 落料滑梯（左/右/整体） | `.SLDPRT` `.stl` |
| `相机固定.SLDPRT`、`零件2.SLDPRT` | 相机支架、杂项零件 | `.SLDPRT` |

## 三、格式说明与打印建议

| 扩展名 | 说明 |
|---|---|
| `.SLDPRT` | SolidWorks 零件源文件（可用 Fusion 360 / SolidWorks / FreeCAD 打开） |
| `.STEP` | 通用 CAD 交换格式，跨软件最稳，改尺寸请优先用它 |
| `.STL` | 3D 打印网格（可直接切片）；文件名里的 `_整件` 表示整件，带数字前缀的是拆分件 |
| `.3mf` | 切片工程（含摆放/支撑设置），直接用 Bambu Studio / PrusaSlicer 打开 |

- 材料建议 PLA / PETG；齿轮类 30%+ 填充、0.15~0.2 mm 层高；主体 3~4 圈壁厚。
- `.SLDPRT` 的比例/单位以 SolidWorks 打开为准；**只关心打印就直接用 `.STL`**。
- 打印件与金属件（M3/M4 螺钉、轴承、光轴、同步轮）的配合以 `03_设计与尺寸/` 的尺寸链为准。
