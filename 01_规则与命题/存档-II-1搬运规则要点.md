## 一、硬性红线（踩了直接没成绩）
- **尺寸**：铅垂方向投影 ≤ 边长 **300mm 正方形**，高度 ≤ **400mm**（含所有软质线材）。**机械臂允许做成可折叠，出发后可自行展开，展开后尺寸不受限**。
- **电源**：**只能用 1 个装在车体内部的电源，电源种类不限**（不能用液体/有腐蚀污染的），**比赛过程中（含调试）不能更换**。→ **规则原文没有 12V 上限！**
- **一键启动**：车上必须有明确标识的"一键式"启动，**只有一次启动机会**；启动时间到没启动，本轮结束。
- **全自主**：不能用任何方式遥控。**但允许比赛过程中与笔记本电脑通讯**，只是运行中不能碰笔记本、不能遮挡场地（仅允许垂直向下补光）。
- **物料必须放在车上运**：不允许用手爪夹持物料运送；**每次抓1个，放到车上之后才能抓下一个**（车上可带 1~3 个）。物料没放到车上不能往下个区域走（本区域内不受限），否则不计成绩但计时照走。
- **放下即定局**：物料底面一旦接触地面即为放置完毕、按该位置定环数；**再移动该物料，本轮立即结束**。
- **不能推行**：把物料在场地推行移动 → 结束比赛。
- **不能出车道**：离开启停区后只能在灰色车道上行驶，铅垂投影越过车道（机械臂除外）进入其它颜色区域 → 本轮结束。
- **15秒不动**（等转盘时间另加 8 秒）→ 本轮结束。
- **掉落物料不取出**，自行取出 → 本队本轮结束。
- **禁止成品套件拼装**；除标准件外，非标零件必须自主设计制造。比赛期间（含调试）不能更换任何零部件。
- **任务码显示装置**：必须装在车上部醒目位置、**亮光显示**、不被遮挡、**字体高度 ≥ 12mm**，能显示所有任务码及完成情况信息。
- **文档匿名**：文档里出现地名、单位名、姓名、电话号码或无关特殊符号 → **任务命题文档 0 分**。

## 二、场地（2400×2400mm）
- 灰色行车道，中间十字车道宽 **400mm**；四个淡黄色区 450×450mm；其余亚光白色。
- **启停区 ×2**：300×300mm。
- **原料区**：顶面为**直径 300mm 的圆盘**，总高 80~100mm。**电动转盘**，转向随机，转盘上均匀放 3 个物料、**中线呈 120° 夹角**，匀速 **6~10 秒/圈**，停止位置有误差。初赛时转盘转向、停留次数和时间以现场为准。
- **暂存区 / 粗加工区**：各为 **580×150mm**，表面有测量摆放精度的**圆环 1~6 环**，圆环线宽 1.5mm，环中间标数字（就是这个数字决定放哪一环）。
- 原料区、二维码板位置**在规定范围内随机摆放**，以现场为准；各区域尺寸和摆放位置都有偏差，**车必须能适应**。

## 三、环号与分数（非线性，越靠内越值钱）
`φ` = 物料最大直径。环外径：1环 `φ+3`、2环 `φ1+5`、3环 `φ2+7`、4环 `φ3+10`、5环 `φ4+10`、6环 `φ5+10`

| 环号 | 1环 | 2环 | 3环 | 4环 | 5环 | 6环 | 6环外 / 倾倒 |
|---|---|---|---|---|---|---|---|
| 分数 | **15** | 10 | 7 | 5 | 3 | 1 | 0 |

判定方式：物料底面能看到某环的边缘，即算在该环内（图片见图6）。

## 四、物料
- 材质 3D 打印 ABS 或 PLA，**尺寸 ≤80mm，重量 ≤100g**。
- 初赛颜色：红、黄、蓝、绿、黑、浅蓝，**每种颜色两个**（现场会有色差，要能适应）。
- 初赛通过扫码确定需要搬运的**三种不同颜色**的物料，**三种颜色用同一种形状**。
- 决赛物料形状颜色多样（圆柱、方块、三角、球、锥、组合体等），现场公布。

## 五、任务码（⚠️ 是**四组**三位数，不是两组！）
- 共 **4 组三位数**，用 `+` 连接。颜色编号：**红1、黄2、蓝3、绿4、黑5、浅蓝6**。
- 第1组 = 第一批三个物料的**颜色和搬运顺序**
- 第2组 = 第一批物料在**粗加工区和暂存区**的放置位置（环号）
- 第3组 = 第二批三个物料的**颜色和搬运顺序**
- 第4组 = 第二批物料在**粗加工区**的放置位置（第二批在暂存区是码垛，位置由第一批决定，故不单独给）
- 例：`156+123+516+231` → 第一批顺序=红、黑、浅蓝，放在粗加工区/暂存区的 1、2、3 号圆环；第二批顺序=黑、红、浅蓝，放在粗加工区的 2、3、1 号圆环。

> ⚠️ 第2组的精确含义原文表述较含糊（"分别放置在粗加工区和暂存区的1、2、3号圆环上"）。**赛前找裁判或现场确认**：是粗加工区与暂存区共用同一组环号，还是各有分工。

## 六、二维码板
- 每个赛场内侧**垂直**安装 **1 块 A4 大小（横放）** 的二维码板，位置在规定范围内随机摆放。
- 二维码在板子中间，**尺寸 80×80mm（含边框）**，随机产生。

## 七、初赛流程（注意：粗加工区是**中转站**，要搬两次）
1. 扫码读任务码 → **把任务码显示在显示装置上**
2. 到原料区，按顺序从转盘上取第一批 3 个物料**放上车**（每次1个）
3. 携 1~3 个物料 → 运到**粗加工区**，按顺序放到规定圆环上
4. **再把粗加工区的物料取回车上** → 运到**暂存区**，按顺序放到规定圆环上
5. 返回原料区取第二批 3 个 → 重复 2~4（粗加工区）
6. 第二批在暂存区**只能在第一批物料上码垛**：要求**颜色一致**且第一批放置正确，不掉下即得分
7. 回到抽签确定的启停区，检查显示装置上"抓取正确次数 / 放置正确次数"统计是否正确

## 八、计分办法（原始分，用于排名）
1. 正确读二维码并在显示装置上正确显示 → **2 分**
2. 正确顺序码**持续显示到本轮结束** → **2 分**
3. 每正确抓取 1 个物料（抓到并放到车上）→ **2 分**
4. 粗加工区 / 暂存区**平面放置**按环计分（表见上），非线性
5. 暂存区**码垛**得分同第一批分数（不影响第一批平面放置成绩）
6. 规定时间内完成全部流程回到启停区 → **2 分**
7. 返回后正确显示"正确抓取数量 / 正确放置数量"，**各 2 分**（没抓没放则不得分）

## 九、时间与赛制
- 比赛前有 **5 分钟**场地调试时间。
- 比赛**分两轮**，每轮**调试 3 分钟 + 运行 3 分钟**，每队两次运行机会，**取最好成绩**。
- 调试剩余 **1 分钟**时抽签确定搬运任务；剩余 **30 秒**时车必须停止运行、放到出发位待机；助理裁判按抽签放好二维码板、随机摆物料并启动转盘。

## 十、成绩构成与换算（⚠️ 不是直接得分制）
| 环节 | 项目 | 分数 |
|---|---|---|
| 初赛 | 任务命题文档 A1 | 20（起评 12） |
| 初赛 | 作品创意设计 A2 | 10（起评 6） |
| 初赛 | 现场初赛 A3 | 70 |
| 初赛总成绩 A | | 100 |
| 决赛 | 创新实践 B1 | 30（起评 18） |
| 决赛 | 现场决赛 B2 | 70 |
| 决赛总成绩 B | | 100 |

**换算公式（按名次，N = 参赛队数）**：
- `A1 = 20 − 8/(N−1) × (名次−1)` → 区间 12~20
- `A2 = 10 − 4/(N−1) × (名次−1)` → 区间 6~10
- `A3 = 70 − 28/(N−1) × (名次−1)` → 区间 42~70
- `B1 = 30 − 12/(N−1) × (名次−1)` → 区间 18~30
- `B2 = 70 − 28/(N−1) × (名次−1)`

→ **关键推论**：分差被名次压缩，最后一名也能拿 12+6+42 = 60/100。所以**重点是把现场初赛名次顶上去**（A3 跨度 28 分，是三块里最大的），文档和创意设计保底即可、别翻车。文档匿名违规 = 直接 0 分，风险最大。

**同分排序**：初赛总成绩相同 → 现场初赛成绩高者优先 → 运行时间（完成全部任务）短者优先 → 抽签。决赛同分同理。

## 十一、必须提交的材料（初赛第一环节）
**报到时提交**，纸质版一式一份 + 电子版 1 份（**合并为一个 PDF**），共 4 份文件，各 5 分：
1. 作品结构设计方案（5分）
2. 作品控制系统电路设计方案（5分）
3. 决赛任务命题方案（5分）
4. 决赛任务场景策划（5分，含规划决赛场地、放物料区域及位置、物料放置方式，并给出物料形状、尺寸及零件图——工程图 + 三维图）

另需提交**与设计制作有关的不超过 3 分钟的视频 1 份**。除内容质量外，**排版规范、格式装订也计分**。

## 十二、作品创意设计（A2，10分）
- 创新性 4 分（符合主题、外形/内部结构有新意）
- 美观性 3 分（整体美观、合理、实用）
- 合理性 3 分（内外部结构合理、制造精细、拆卸方便）
- ⚠️ **同校作品外形雷同全部给 0 分**

## 十三、决赛
- **创新实践 B1（30分）**：现场抽签物料 → **手爪替换 + 机器人联调**。用现场提供的装备材料，现场设计制作零部件并替换原有零件安装调试。**4 小时内完成得满分，超过 4 小时此项不得分**。未按规定完成零件制作 → 取消资格；未把新加工零件换到作品上完成调试和后续现场运行 → **扣决赛总成绩的 50%**。自带拆装/调试工具。
- **现场决赛 B2（70分）**：流程参照初赛，按现场发布的决赛任务执行，两次机会取最好。

## 十四、奖项
一等奖 ≤10%、二等奖 ≤20%、三等奖 ≤30%。**"未能完成比赛"不参与评奖**（车不能启动 / 任一环节弃权 / 严重安全事故或不守纪律 / 队员资格不符 / 作品不符主题 / 裁判专家组判定的其它情况）。结果公布后 **24 小时内**未提成绩异议不再受理。
