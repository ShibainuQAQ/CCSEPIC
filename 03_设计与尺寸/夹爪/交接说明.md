## 2. 三个关键结论（先接受再动手）

1. **开口必须是 64mm，不是 50mm**。规则写"货物尺寸在 40mm 正方形范围内"，但流程写"**裁判随机放货、方向和位置随机**"——40mm 方货斜放 45° 时沿开合方向占 **40√2 = 56.6mm**；开口 50 会顶在货的角上，抓不住/推飞，而**掉落 = 本轮结束**。
2. **夹爪真实包络 = 82mm 高**（老参数表写的 26 只算了框体，没算两根齿条+齿轮+舵机）。→ **框架立柱要从 260 加到 ~310，整机 ~350**（规则上限 450，仍余 100）。**型材还没切，现在改零成本。**
3. **"每盒 4 件 40mm"和"爪子伸得进盒"冲突**：手指要插在货与盒壁之间，盒内腔 82 + 爪厚 3.5 时，4 件最大只能放 36.5mm 的货。要放 40mm 得内腔 ≥88（4040 立柱下最多 87）。三条出路待队内拍板：**换 3030 型材 / 货物上限降到 ≤36 / 接受风险**。

## 3. 电控同学只需要知道这几条

- 舵机：**DS3225 · 必须买 270° 版**（按 M1.5-z14 齿轮算，全行程 56mm 需要 **152.8°** 转角；180° 版会把齿轮改成 z16、本体高变成 30）
- 驱动：主控 **PWM 直驱**，不引入总线舵机/额外电源域（规则要求单电源内置）
- 到位/触货：**机械硬限位定开口与闭口**；抓力靠**压簧 5N**，不靠舵机角度；**触货用微动开关**（浮动爪被顶退 1.5~2mm 触发 → 立即停舵机），**禁止只用延时**
- 采购增补 6 样小件共 25~40 元（MF106ZZ 轴承 / Ø6 导杆 / 压簧 / 微动开关加量 / 爪垫 / M1.5 成品齿条兜底）

## 4. ⚠️ 打印/装配前必须知道的三条

1. **stl\ 里的件是"概念模型"，不能直接拿去打印**：主框没挖减轻孔、吊耳上的轴承孔没打穿、齿条/爪板是按最大开口姿态摆的。**要打印必须用 `fusion_gripper.py` 在 Fusion 里生成实体后导出**。
2. **`fusion_gripper.py` 里有 5 处常数是我最后手改的，还没在 Fusion 里跑过**（吊耳 X 36~41、孔径中心 X 38.5、吊耳 Y ±(13.5~26.5)、Z 下限 5、导杆 X 26~70）。**请先跑一次，再用 Inspect → Interference 做干涉检查确认**，尤其是"爪板连接耳（随爪移动，扫过 X 4~35.5）与固定吊耳的轴承孔外圆柱"这一处。
3. **有一处 0.25mm 干涉是几何上躲不掉的**：连接臂内端尖角在行程末段会擦过齿轮齿顶圆边缘。处理办法二选一：**在模型里给臂内端倒 2mm 角**（推荐，该角不承力）或**把行程从 28 收到 26**（开口仍有 60 ≥ 56.6，够用）。**不要靠现场锉刀改。**
