# 夹爪文件夹 · 用法说明

> 2026-09-17 建。**这里放的是"把夹爪缩到刚刚好"的整套东西**：算尺寸的工具 + 校核报告 + 图纸 + STL + Fusion 生成脚本。
> 上游文档：《夹爪设计参数表.md》《框架与布局尺寸.md》；本文件夹的数值以 `gripper_design.py` 的输出为准。

## 1. 文件夹里有什么

| 文件 | 是什么 | 怎么用 |
|---|---|---|
| `gripper_design.py` | **参数化设计/校核/建模工具**（纯 Python，只依赖 numpy，出图和 STL 用 PIL） | `python 夹爪\gripper_design.py` |
| `夹爪校核报告.txt` | 工具自动生成的报告：尺寸链、红线校核、质量估算 | 直接看；改完参数重跑就更新 |
| `夹爪图纸.png` | 工具自动生成的三面板图：①正视 ②侧视 ③"开口 50 为什么不行"对照 | 可直接贴进说明书/队内讨论 |
| `stl\*.stl` | 每个零件的 STL（齿轮/齿条/爪板/主框/导杆/轴承/舵机）+ `夹爪总成.stl` | 拖进 Fusion、Windows"3D 查看器"、切片软件都能看 |
| `fusion_gripper.py` | **Fusion 360 脚本**：在 Fusion 里一键生成真·实体（可导出 STEP 去打印/出图） | 见下面第 3 节 |
| `用法.md` | 本文件 | — |

## 2. 改尺寸怎么改（推荐流程）

1. 打开 `gripper_design.py`，**只改最上面【参数区】**（开口、爪厚、齿轮模数/齿数、框尺寸…）。
2. 运行 `python 夹爪\gripper_design.py`。
3. 看终端/报告【2】红线校核：**出现 ❌ 就别往 Fusion 里搬**，先改参数。
4. 报告会自己算出：行程、舵机转角、下潜净空、每盒能放多大的货、**夹爪真实包络高**、以及**框架立柱需要多高**。

> ⚠️ 本机控制台是 GBK，脚本已改成"写 UTF-8 文件 + 尽量回显"，不会崩；看图别用 `cv2`（本工具用 PIL，支持中文路径）。

## 3. 在 Fusion 360 里生成实体（队友操作，约 1 分钟）

1. 打开 Fusion 360 → 顶部 **实用程序 / Utilities** → **附加模块 / Add-Ins** → **脚本和附加模块 / Scripts and Add-Ins**。
2. 切到 **脚本 / Scripts** 标签 → 点绿色 **＋** → 选 `fusion_gripper.py` → **运行 / Run**。
3. 浏览器树里会出现中文命名的元件（爪板-左/右、齿条-上/下、齿轮、主框、导杆、轴承、舵机）。
4. 想导出：右键元件 → **导出 / Export** → 选 STEP（给加工/装配）或 STL（给切片）。
5. 想改尺寸：改脚本顶部参数区再跑一次；脚本可重复运行（会先清理上一次生成的同名元件）。

> ⚠️ Fusion 脚本里的数值必须与 `gripper_design.py` 保持一致；**以设计工具为准**（它会自动校核）。

## 4. 这一版得出的四个关键结论（先看这个）

1. **开口必须 ≥ 56.6mm，定 64mm**。规则写的是"货物尺寸在 40mm 正方形范围内"，但流程写的是"**裁判随机放入托盘，方向和位置随机**"——40mm 方货斜放 45° 时，沿爪子开合方向占 **40√2 = 56.6mm**，按老参数表的开口 50 会顶在货的角上（抓不住/推飞，掉落即本轮结束）。
2. **夹爪真实包络高 ≈ 82mm，不是老参数表的 26mm**。26 只算了框体，没算两根齿条 + 齿轮 + 舵机。它直接决定框架高度：**立柱要从 260 加长到 ~310，整机 ~350（规则上限 450 ✅）**。⚠️ **型材还没切，现在改是零成本。**
3. **"每盒 4 件 40mm"和"爪子伸得进盒"是冲突的**：手指必须插在货与盒壁之间，所以盒内腔 82 时，4 件 2×2 能放的最大货边只有 **36.5mm**（爪厚 3.5）。要真放 4 件 40mm，内腔得 ≥88，而 4040 立柱下 3 列最多 87 —— 需队内拍板（换 3030 型材 / 货物降到 ≤36 / 接受风险）。详见报告【2】。
4. **两处结构坑（2026-09-17 下午已修，工具里已生效）**：
   - **舵机必须同轴直驱**：原先想把舵机放在齿轮正下方，会和上齿条撞（实测重叠 40×8×7mm）→ 若靠偏心联轴器，M1.5 齿轮凑不出 8mm 的整数齿中心距。改法：**传动（齿轮/齿条）挪到前侧 Y 2~12，舵机放它后面 Y 13~51.5，轴心 X=0 / Z=66.5 与齿轮同心** → 直接插齿轮，不需要偏心件。
   - **导杆要有固定支撑**：导杆在 Z=12，而主框在 Z 48~82，够不到 → 每侧加 **2 个固定吊耳**（从主框底垂到 Z=12，带 Ø10 轴承孔，孔位 X ±26/±38），导杆挪到**爪板后方 Y=20**；校核结果：开口位导杆 26~70、闭口位 −2~42，两个孔始终在导杆上 ✅。

## 5. 还没拍板 / 下一步

- [ ] ⚠️ **装配前必须在 Fusion 里做一次干涉检查（Inspect → Interference）**，重点看一处：**爪板连接耳（随爪移动）与固定吊耳／轴承外圆柱**。连接耳沿 X 扫过 4~35.5，所以**吊耳的轴承孔外圆柱必须完全落在 |X| > 35.5 之外**。
  **已定的正确尺寸（2026-09-17 晚，我已直接改进 `fusion_gripper.py`）**：
  - **吊耳 X 36~41（板厚 5）** —— 5mm 厚足够放下宽 3 的 MF106ZZ；⚠️ 孔 Ø10 的"直径"在吊耳的 Y-Z 平面里，不占 X 向空间（子代理原先按"Ø10 要占 10mm X 宽度"论证"放不下"，前提错了）。
  - 吊耳 **Y ±(13.5~26.5)**（13 宽，孔心 Y=±20）、**Z 5~48**；每爪 2 个（Y 向分开 = 抗倾覆），共 4 个，**全部在盒口内腔 ±41 以内** ✅
