# 快速开始

> 目标：从零把上位机工具跑起来，把固件编出来、烧进去，然后手动控制 → 视觉标定 → 抓取一件货。
> 遇到报错先看 [02_常见问题](02_常见问题.md)，那里记录了本项目真实踩过的坑。

## 0. 你需要的东西

| 类别 | 具体 |
|---|---|
| 电脑 | Windows + Python **3.8+**（本项目实测在 3.11/3.14 上都跑过） |
| 硬件 | STM32F103C8T6 板、USB-TTL（CH340）、K210（CanMV）相机、X/Y 闭环步进 ×2 + 驱动器（ZDT X42）、MG996R 舵机 ×2、TJC 串口屏 |
| 电源 | 6S 25.2 V 电池为主回路；**舵机必须独立 5.5~6 V / ≥3 A 供电**（不许从板子 5 V 取电 ✗） |
| 烧录 | ST-Link + Keil MDK（也可用串口 ISP，但本项目走 ST-Link） |

完整接线见 [`09_固件/接线总表-C8T6-20261004.md`](../09_固件/接线总表-C8T6-20261004.md)。

## 1. 装 Python 依赖

```bash
pip install -r hw_bridge/requirements.txt
# 国内网络装 opencv 慢/失败：加 -i https://pypi.tuna.tsinghua.edu.cn/simple
```

历史说明：早先这些库是用 `hw_bridge/vendor/` 原样入库的，现已改为 pip 安装（见 `requirements.txt` 注释）。

## 2. 确认串口

```bash
python hw_bridge/tools/port_probe.py --list
# 认 STM32（8E1，回 OK pong）：
python hw_bridge/tools/port_probe.py COM11 --baud 115200 --parity E --send "PING" --crlf --listen 2
```

⚠️ **USB 口号会变**（本项目调试期：STM32 从 COM14 漂到 COM11，K210 从 COM5 漂到 COM15）。
上位机脚本已**自动认口**（`pick_place.py` 发 `PING`、`vision_pick.py` 找 CanMV 提示符），一般不用手填；
但 `step_test.py`、`port_probe.py` 这类底层工具仍要手动给 `--port`。

## 3. 编译固件

```bash
python 09_固件/build.py
```

- 依赖 Keil MDK 自带的 `armclang`，路径写死在 `09_固件/build.py` 的 `KEIL_BIN`（默认 `C:\111\keil\ARM\ARMCLANG\bin`），**换机器要改这一行**。
- 还需要 Keil 器件包 `Keil.STM32F1xx_DFP 2.4.1`（提供 `stm32f10x.h`）与 `ARM::CMSIS 5.9.0`。
- 产物：`09_固件/build/m1.axf`（烧录用）+ `m1.bin`。

## 4. 烧录

```powershell
# 方式 A：Keil 命令行 + ST-Link（推荐，本项目用法）
powershell -ExecutionPolicy Bypass -File 09_固件\flash_keil.ps1

# 方式 B：直接用 Keil uVision 打开 09_固件\keil\m1.uvprojx 点 Download
```

⚠️ `flash_keil.ps1` 在默认执行策略下会被拦（"未数字签名"），所以加 `-ExecutionPolicy Bypass`。
烧完若程序不跑，**拔插一次 USB 或按复位**（Keil 会把内核停在 halt 状态）。

验证：开串口发 `VER`，应回 `OK fw=0.8.2 proto=1`（版本号见 `09_固件/src/main.c`）。

## 5. 手动控制（先把机构走通）

```bash
python hw_bridge/tools/manual_pick.py
```

| 键 | 作用 |
|---|---|
| `w` / `s` | Z 抬 / 降（默认 100 µs 一步，大写 ×5） |
| `a` / `d` | 夹爪张开 / 夹紧 |
| `j` / `l` | X 往 −X / +X（5 mm） |
| `i` / `k` | Y 往 −Y / +Y（5 mm） |
| `mz`/`mz2`、`mg`/`mg2`、`mx`/`mx2` | 记录当前位置（Z 抬起/放下、夹爪开/合、货物/放置点） |
| `gz`/`gz2`、`gg`/`gg2`、`gx`/`gx2` | 回到上面记录的点 |
| `p` | 打印状态（x/y 步数、Z/夹爪脉宽） |
| `M` | 读板子引脚状态（EN 是否使能、PUL/DIR/EN 是否配成输出）——**"某轴不动"的第一站** |
| `T` | 以 20 Hz 连续发 20 秒脉冲（给万用表量 PUL 脚用；正常速度只发 0.1 秒测不到） |
| `x` | 退出（**退出后串口才释放**） |

⚠️ **安全位 = 放置点正上方 + Z 最高，它同时是 +X 机械极限** —— 手动时不要往 +X 顶。
⚠️ 开串口会让板子复位（CH340 的 DTR/RTS 接了复位）⇒ **一开串口位置就归零、EN 失能**，属正常现象。

## 6. 视觉标定（相机被碰过 / 换 Z 高度 / 换相机才需要重做）

```bash
# ① 只重算比例 + 旋转（龙门沿 −X 走 40mm 拍两张，最后自动回原位）
python 08_视觉/vision/calibrate_2point.py --dist -40

# ② 只换原点（"喂 0,0 点"，比例旋转不动）：见 docs/02_常见问题.md 的"坐标系"一条
```

标定数据写在 `08_视觉/vision/vision_pick.py` 的 `CAL`：**比例 + 旋转 + 一个锚点**。
⚠️ 相机装在**龙门**上 ⇒ 像素↔毫米关系是"相对当前夹爪位置"的，**夹爪停在哪都不影响**；
但 **Z 高度会改变比例** ✗ ⇒ 拍照与抓取时必须让 Z 保持在最高（脚本已保证）。

## 7. 抓一件货

```bash
# 先空跑：只拍照、识别、算坐标，不动机器
python 08_视觉/vision/vision_pick.py --color yellow --dry

# 确认选中的是想要的那件后，真抓：到放置点后夹爪开到最大让货自由下落
python 08_视觉/vision/vision_pick.py --color yellow --place 0 0 --drop
```

常用参数：

| 参数 | 说明 |
|---|---|
| `--color yellow/green/blue/any` | 按颜色选（`any` = 选 X 最靠近 0 的，移动最短） |
| `--shape hex/circle/triangle/...` | 按形状**子串**筛选；⚠️ 真实光照下形状判据仍会偶发跳变，见 FAQ |
| `--place X Y` | 放置点（相对脚本启动位置；**X 必须 ≤ 0**） |
| `--dry` / `--drop` | 只算不动 / 到点不收 Z 直接松爪 |
| `--zdn` `--zup` `--gopen` `--gclose` | Z 与夹爪脉宽（默认 611/2370、1850/950） |
| `--shot-file 图片` | 用现成照片，不重新拍（离线复算用） |

⚠️ **脚本报"完成"≠ 夹住了货**：舵机无反馈、步进开环。流程跑完请**再拍一张**确认货真的离开了托盘
（`vision_pick.py --color any --dry` 看列表里少没少那件）。
