# 目录说明

本仓库是一台竞赛分拣装置的**完整工程档案**：规则 → 方案 → 机械 → 电控固件 → 上位机 → 视觉 → 实测记录。
下面按"你是谁"给三条阅读路线。

## 一、按读者分路线

| 你是… | 建议顺序 |
|---|---|
| **评委 / 快速了解** | [README](../README.md) → [`02_方案与说明书/`](../02_方案与说明书/) → [`07_概念图/`](../07_概念图/) → [CHANGELOG](../CHANGELOG.md) |
| **想复刻一台** | [docs/01_快速开始](01_快速开始.md) → [`09_固件/接线总表`](../09_固件/接线总表-C8T6-20261004.md) → [`03_设计与尺寸/`](../03_设计与尺寸/) → [`models/`](../models/) → [`04_采购/`](../04_采购/) |
| **想学技术细节** | [`09_固件/src/board.c`](../09_固件/src/board.c)（软步进/舵机/时间基准）→ [`08_视觉/vision/pc_detect.py`](../08_视觉/vision/pc_detect.py)（形状判据）→ [`08_视觉/vision/vision_pick.py`](../08_视觉/vision/vision_pick.py)（标定）→ [`hw_bridge/protocol.md`](../hw_bridge/protocol.md) → [docs/02_常见问题](02_常见问题.md)（踩坑记录） |

## 三、命名与约定

- **数字前缀目录 = 项目知识库**（`01_`…`11_`），按"规则→方案→设计→采购→工具→参考→图→代码"排列。
- 文件名里的日期（如 `-20261004`）是**该文档最后一次重大更新的日期**，不是版本号。
- 以 `_` 开头的文件/目录是**脚本产物或内部草稿**，已在 `.gitignore` 中排除，不随仓库分发。
- 固件版本号在 [`09_固件/src/main.c`](../09_固件/src/main.c) 的 `FW_VERSION`，发版记录见 [CHANGELOG](../CHANGELOG.md)。
