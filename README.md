# 工创赛 II-2 智能分拣 · 项目仓库

> 2026 年四川省大学生工程实践与创新能力大赛 · 项目 II-2「智能分拣」
> 龙门式三轴 + 舵机夹爪 · K210 视觉识别（经 PC 处理）· TJC 串口屏显示

---

## 一、任务简介

在 **350×350×450 mm** 的尺寸限制内，制作一台自动分拣装置：**6 个储物盒 + 分拣机构 + 托盘**。

- 待分拣物料边长/直径 ≤ 40 mm，一批 **≥ 12 件、≥ 6 种**（颜色 × 形状组合）
- **同形同色**的物料放入同一个盒，**单盒 ≤ 4 件**
- 每件物料须先**逐件显示**（屏上展示名称/图片/序号）再分下一件
- 物料在搬运中掉落即本轮结束

完整规则见 [`01_规则与命题/`](01_规则与命题/)（官方 PDF + 规则要点提取）。

## 二、总体方案（方案 B）

```
K210 摄像头拍照 ──USB串口(COM5)──▶ PC 端识别（OpenCV + HSV 阈值）
                                      │  两点标定：像素 → 龙门 mm 坐标
                                      ▼
                            PC ──USB-TTL CH340(COM14)──▶ STM32F103C8T6
                                                        ├─ 3× 步进电机（龙门 XYZ）
                                                        ├─ 舵机 Z 轴 / 舵机夹爪
                                                        └─ USART2 ──▶ TJC 串口屏（显示物料名称/图片/计数）
```

- **校赛形态**：K210 直接连 PC，识别与坐标解算全部在 PC 完成，STM32 只负责运动控制（有线，稳定优先）。
- **最终形态**：力争 K210 与 STM32 直连（USART3 已预留，尚未启用），并评估 ESP 无线链路（见 `11_ESP无线/`）。

## 三、硬件配置

| 模块 | 型号 / 关键参数 |
|---|---|
| 主控 | STM32F103**C8T6**（64 KB Flash / 20 KB RAM） |
| 视觉 | K210（CanMV_Yahboom 固件） |
| 步进电机 ×3 | 细分后 **80 步/mm**；TIM4 10 kHz 软件步进中断；最高 **5000 Hz ≈ 62.5 mm/s** |
| Z 轴舵机 | MG996R，TIM3-CH3 = **PB0**，50 Hz PWM，脉宽 611~2370 µs（611 = 最低点） |
| 夹爪舵机 | MG996R，TIM3-CH4 = **PB1**，50 Hz PWM，脉宽 750~2140 µs（1850 张开 / 950 闭合 / 2140 松爪投放） |
| 串口屏 | TJC 800×480，USART2（PA2/PA3，9600 8N1），显示物料名称 + 图片 + 序号 + 计数 |

物料实物照片（黄/绿/蓝 × 7 种形状）见 [`工创赛物料/`](工创赛物料/)。

## 四、通信速查

| 链路 | 接口 | 参数 |
|---|---|---|
| PC ↔ STM32 | USART1（PA9/PA10，USB-TTL CH340 = **COM14**） | 115200 **8E1** |
| PC ↔ K210 | K210 USB（**COM5**） | 115200 8N1 |
| STM32 ↔ TJC 屏 | USART2（PA2/PA3） | 9600 8N1 |
| STM32 ↔ K210（预留） | USART3（PB10/PB11） | 未启用 |

> COM 口编号以 `hw_bridge/tools/port_probe.py` 实测为准；无线桥（板载 ESP）已禁用。

## 六、常用操作

```powershell
# 0) 探测串口
python hw_bridge/tools/port_probe.py

# 1) 回安全位（放置点正上方、Z 最高）
python hw_bridge/tools/go_safe.py

# 2) 手动控制（w/s=Z  a/d=夹爪  i/j/k/l=XY  mz/mg/mx=记录  p=状态  x=退出）
python hw_bridge/tools/manual_pick.py

# 3) 视觉引导抓取单件（拍照 → 识别 → mm 坐标 → 抓取 → 放置）
python 12_视觉/vision/vision_pick.py --color yellow --speed 5000 --zsettle 6.0 --zlift 5.0 --gsettle 0.35 --zdn 611 --drop

# 4) 连续抓取某颜色全部物料（第 1 件放 (0,0)，之后每件 -70 mm 排开）
python 12_视觉/vision/vision_pick_all.py --color green

# 5) 两点标定（视觉像素 → 龙门 mm）
python 12_视觉/vision/calibrate_2point.py --dist -40
```

固件：`09_固件/build.py` 编译、`09_固件/flash_keil.ps1` 烧录；协议见 [`hw_bridge/protocol.md`](hw_bridge/protocol.md)。

## 八、安全须知（重要）

1. **安全位置 = 放置点正上方 Z 最高**，它同时是 **+X 机械极限** —— 任何命令的 X 不得为正（脚本已强制拒绝，除非显式 `--allow-plusx`）。
2. 每次抓放流程以 `ZERO all` 归零开始（以启动时夹爪位置为原点），结束必须 **Z 升到最高、原地停住**，不做多余 XY 移动。
3. Z 轴与夹爪舵机**无位置反馈**，到位判断只能靠固定延时；延时异常变长通常意味着供电不足或机械卡滞（MG996R 堵转 ≈ 2.5 A）。
4. 紧急停机 = 直接断电；异响/顶死立即断电检查。
